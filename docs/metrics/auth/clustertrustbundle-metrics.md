# ClusterTrustBundle Metrics

| Metric name                                               | Metric type | Description                                                                                                                             | Labels/tags                                                                                                                 | Status       |
| --------------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------ |
| kube_clustertrustbundle_annotations                       | Gauge       | Kubernetes annotations converted to Prometheus labels controlled via [--metric-annotations-allowlist](../../developer/cli-arguments.md) | `clustertrustbundle`=&lt;clustertrustbundle-name&gt; <br> `annotation_CLUSTERTRUSTBUNDLE_ANNOTATION`=&lt;CLUSTERTRUSTBUNDLE_ANNOTATION&gt; | EXPERIMENTAL |
| kube_clustertrustbundle_labels                            | Gauge       | Kubernetes labels converted to Prometheus labels controlled via [--metric-labels-allowlist](../../developer/cli-arguments.md)           | `clustertrustbundle`=&lt;clustertrustbundle-name&gt; <br> `label_CLUSTERTRUSTBUNDLE_LABEL`=&lt;CLUSTERTRUSTBUNDLE_LABEL&gt; | EXPERIMENTAL |
| kube_clustertrustbundle_created                           | Gauge       | Unix creation timestamp                                                                                                                 | `clustertrustbundle`=&lt;clustertrustbundle-name&gt;                                                                        | EXPERIMENTAL |
| kube_clustertrustbundle_info                              | Gauge       | Information about clustertrustbundle.                                                                                                   | `clustertrustbundle`=&lt;clustertrustbundle-name&gt; <br> `signer_name`=&lt;clustertrustbundle-signer-name&gt;              | EXPERIMENTAL |
| kube_clustertrustbundle_certificates                      | Gauge       | Number of CERTIFICATE PEM blocks in the clustertrustbundle.                                                                             | `clustertrustbundle`=&lt;clustertrustbundle-name&gt;                                                                        | EXPERIMENTAL |
| kube_clustertrustbundle_earliest_expiry_timestamp_seconds | Gauge       | Unix timestamp of the earliest NotAfter across the parsable certificates in the clustertrustbundle. Omitted if no certificate parses.   | `clustertrustbundle`=&lt;clustertrustbundle-name&gt;                                                                        | EXPERIMENTAL |
